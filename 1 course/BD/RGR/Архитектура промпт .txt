1.	Периферийный уровень (филиалы/отделения)
•	Изображается в нижней части диаграммы 3-5 прямоугольниками, обозначающими филиалы
•	Каждый филиал содержит:
o	Модуль приема данных (иконка "входящий документ")
o	Модуль первичной идентификации (иконка "лупа" или "сканер")
o	Локальное хранилище сырых данных (иконка "база данных" с замком)
•	Соединяется с региональными центрами стрелками с подписью "Защищенная передача (TLS)"
2.	Региональный уровень (центры обработки)
•	Располагается в середине диаграммы 2-3 крупными блоками
•	Каждый центр включает:
o	Шлюз безопасности (иконка "щит")
o	Модуль предварительной обработки (иконка "конвейер")
o	Буферное хранилище (иконка "база данных" с часами)
•	Соединяется с центральным узлом двойной стрелкой с подписью "Криптозащищенный канал"
3.	Центральный уровень (головной офис)
•	Верхняя часть диаграммы в виде защищенного облака
•	Основные компоненты:
o	Ядро обезличивания (центральный круг с иконками:
	Токенизатор (ключ)
	Псевдонимизатор (маска)
	Агрегатор (график)
o	Система управления ключами (сейф с ключами)
o	Блокчейн-журнал (цепочка блоков)
o	Главное хранилище (3 связанных сервера с подписями:
	Обезличенные данные
	Таблицы соответствия
	Метаданные операций
4.	Дополнительные элементы:
•	В правом нижнем углу - легенда с обозначениями:
o	Типы линий соединений
o	Уровни защиты данных
o	Условные обозначения компонентов
•	В левом верхнем углу - логотип системы
•	По периметру - стилизованный щит, символизирующий защиту
Рекомендации по визуализации:
1.	Использовать цветовую дифференциацию:
•	Красный/оранжевый - для компонентов обработки
•	Синий - для хранилищ
•	Зеленый - для защитных механизмов
2.	Расположить стрелки передачи данных:
•	Восходящие - сплошные линии
•	Нисходящие - пунктирные
•	Синхронизация - волнистые
3.	Добавить поясняющие надписи:
•	На компонентах - краткие названия (2-3 слова)
•	На соединениях - тип передачи данных
•	Внутри центрального облака - лозунг системы ("Защита через распределение")

        function roundedRect(x, y, width, height, radius) {
            ctx.beginPath();
            ctx.moveTo(x + radius, y);
            ctx.lineTo(x + width - radius, y);
            ctx.quadraticCurveTo(x + width, y, x + width, y + radius);
            ctx.lineTo(x + width, y + height - radius);
            ctx.quadraticCurveTo(x + width, y + height, x + width - radius, y + height);
            ctx.lineTo(x + radius, y + height);
            ctx.quadraticCurveTo(x, y + height, x, y + height - radius);
            ctx.lineTo(x, y + radius);
            ctx.quadraticCurveTo(x, y, x + radius, y);
            ctx.closePath();
            ctx.fill();
            ctx.stroke();
        }

        // Функция для рисования облака
        function drawCloud(x, y, width, height) {
            const segments = 8;
            const segmentAngle = (Math.PI * 2) / segments;
            const radius = height / 2;
            
            ctx.beginPath();
            for (let i = 0; i < segments; i++) {
                const angle = segmentAngle * i;
                const nextAngle = segmentAngle * (i + 1);
                
                const offset = (i % 2 === 0) ? radius * 0.9 : radius * 1.1;
                
                const x1 = x + width/2 + Math.cos(angle) * offset;
                const y1 = y + height/2 + Math.sin(angle) * offset;
                const x2 = x + width/2 + Math.cos(nextAngle) * offset;
                const y2 = y + height/2 + Math.sin(nextAngle) * offset;
                
                if (i === 0) {
                    ctx.moveTo(x1, y1);
                }
                
                const cx = x + width/2 + Math.cos(angle + segmentAngle/2) * offset * 1.2;
                const cy = y + height/2 + Math.sin(angle + segmentAngle/2) * offset * 1.2;
                
                ctx.quadraticCurveTo(cx, cy, x2, y2);
            }
            ctx.closePath();
            
            const gradient = ctx.createRadialGradient(
                x + width/2, y + height/2, 0,
                x + width/2, y + height/2, radius * 1.5
            );
            gradient.addColorStop(0, '#e6f3ff');
            gradient.addColorStop(1, '#b8d9ff');
            
            ctx.fillStyle = gradient;
            ctx.fill();
            ctx.strokeStyle = '#5a9bd5';
            ctx.stroke();
        }

            ctx.strokeStyle = '#ff6f00';
            ctx.stroke();

            ctx.moveTo(x - size/3, y - size/6);
            ctx.lineTo(x - size/6, y - size/6);
            ctx.lineTo(x - size/6, y - size/3);
            ctx.lineTo(x + size/6, y - size/3);
            ctx.lineTo(x + size/6, y - size/6);
            ctx.lineTo(x + size/3, y - size/6);
            ctx.moveTo(x, y - size/6);
